# AI Smart Attendance Face Recognition

## Project Description
AI Smart Attendance Face Recognition is a Python-based attendance management system that uses face recognition technology to identify registered students and record their attendance automatically.

## Features
- Student registration
- Face image dataset collection
- Face recognition model training
- Automatic attendance marking
- Attendance report generation
- SQLite database for storing student and attendance details

## Technologies Used
- Python
- OpenCV
- SQLite
- Haar Cascade
- Face Recognition
- GitHub

## How to Run
1. Install the required Python packages.
2. Register the students.
3. Capture face images.
4. Train the face recognition model.
5. Start the attendance system.
6. Generate the attendance report.

## Project Structure
- `app.py` - Main application
- `dataset/` - Student face images
- `trainer.yml` - Trained face recognition model
- `attendance.db` - Attendance database
- `requirements.txt` - Required Python packages
